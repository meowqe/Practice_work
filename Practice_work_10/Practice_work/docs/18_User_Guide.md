# Руководство пользователя (18)

Приложение запускается из папки проекта командой `python main.py <команда>`. Список команд: `python main.py --help`. Данные лежат в папке `data/`; другую папку можно указать так: `python main.py --data-dir <папка> ...`.

Если команда не удалась, выводится сообщение `Ошибка: ...` и программа завершается с кодом 1.

## 1. Просмотр каталога

```
python main.py catalog
python main.py catalog --sort price          # по цене
python main.py catalog --sort quantity --desc # по остатку, по убыванию
```

Сортировать можно по `name`, `price`, `quantity`, `brand`, `category`.

Пример результата (`--sort price`):

```
Скакалка | Reebok | Инвентарь | 700 руб. | в наличии: 15
Гантели 5 кг | Reebok | Инвентарь | 1800 руб. | в наличии: 1
Футбольный мяч | Adidas | Мячи | 2500 руб. | в наличии: 2
Баскетбольный мяч | Nike | Мячи | 3000 руб. | в наличии: 5
Спортивный рюкзак | Puma | Аксессуары | 3200 руб. | в наличии: 6
Спортивная форма | Adidas | Одежда | 4500 руб. | в наличии: 10
Футбольные бутсы | Puma | Обувь | 6500 руб. | в наличии: 3
Беговые кроссовки | Nike | Обувь | 8900 руб. | в наличии: 7

Товары, которые заканчиваются (остаток 3 и меньше):

```

## 2. Поиск товара

Поиск идёт по названию и бренду, регистр не важен. Можно добавить фильтры по категории и цене.

```
python main.py search adidas --min-price 2000 --max-price 5000
```
```
Футбольный мяч | Adidas | Мячи | 2500 руб. | в наличии: 2
Спортивная форма | Adidas | Одежда | 4500 руб. | в наличии: 10
```

Только по категории (пустой запрос):

```
python main.py search "" --category Обувь
```
```
Футбольные бутсы | Puma | Обувь | 6500 руб. | в наличии: 3
Беговые кроссовки | Nike | Обувь | 8900 руб. | в наличии: 7
```

Если ничего не найдено, выводится `Ничего не найдено`.

## 3. Добавление в корзину

Название товара нужно писать полностью (регистр не важен), с кавычками, если в нём есть пробелы. Корзина сохраняется между запусками в `data/cart.json`.

```
python main.py cart add "Скакалка" -q 2
python main.py cart add "Спортивный рюкзак"
python main.py cart show
```
```
Добавлено: Скакалка x2
Добавлено: Спортивный рюкзак x1
Скакалка x2 = 1400 руб.
Спортивный рюкзак x1 = 3200 руб.
Итого: 4600 руб.
```

Убрать позицию или очистить корзину:

```
python main.py cart remove "Скакалка"     # Удалено: Скакалка
python main.py cart clear                 # Корзина очищена
```

Типичные ошибки:

| Команда | Сообщение |
|---------|-----------|
| `cart add "Лыжи"` | `Ошибка: Товар 'Лыжи' не найден` |
| `cart add "Гантели 5 кг" -q 5` | `Ошибка: Недостаточно товара 'Гантели 5 кг': на складе 1, в корзине уже 0` |

## 4. Оформление заказа

```
python main.py checkout --customer "Иван Петров" --discount 10
```
```
Заказ №1 оформлен. Покупатель: Иван Петров. Сумма: 7380 руб.
```

(для корзины из рюкзака за 3200 и двух футбольных мячей по 2500, итого 8200, скидка 10%). После оформления заказ записывается в `data/orders.json`, остатки на складе уменьшаются, корзина очищается. Параметр `--discount` необязательный, по умолчанию 0.

Если корзина пуста: `Ошибка: Корзина пуста`.

## 6. Сохранение и загрузка заказов

Заказы сохраняются автоматически при оформлении. Загрузить и показать их:

```
python main.py orders
```
```
№1 | Иван Петров | Спортивный рюкзак x1, Футбольный мяч x2 | 7380 руб.
```

Сохранить копию заказов в другой файл (например, для резервной копии):

```
python main.py orders --export backup.json
```
```
№1 | Иван Петров | Спортивный рюкзак x1, Футбольный мяч x2 | 7380 руб.
Заказы сохранены в файл backup.json
```

Формат файла — JSON, его можно открыть в любом текстовом редакторе. Если заказов ещё нет, выводится `Заказов пока нет`.
