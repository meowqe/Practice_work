# Учебная практика 

## Выполнил: Ким Владислав 3ИП-7-24

Учебный проект по разработке операционной системы на Python с использованием SQLite.  
Выполнен в рамках серии практических занятий.

---

## О проекте

В ходе работы была поэтапно спроектирована и реализована **учебная операционная система** на Python.  
Проект охватывает полный цикл разработки: от анализа предметной области до интеграции модулей,  
тестирования и командной работы с Git.

---

## Что было сделано

### 1. Границы ОС и нефункциональные требования
- Определены границы системы: что реализуется, что имитируется.
- Разработаны сценарии использования для ролей: пользователь, администратор, система.
- Сформулированы нефункциональные требования (производительность, надёжность, безопасность, поддерживаемость).
- Проведён анализ рисков.
- Создан базовый прототип: `db.py`, `syscalls.py`, `shell.py`.

### 2. Архитектура и API ядра
- Построена диаграмма компонентов: `shell.py` → `syscalls.py` → `kernel.py` → подсистемы → `db.py`.
- Описаны контракты функций (предусловие, постусловие, побочный эффект).
- Спроектированы структуры данных: процесс, файл, пользователь, запись журнала.
- Реализованы заглушки системных вызовов с логированием в SQLite.
- Расширена оболочка командами `whoami`, `login`, `create`, `ls`, `ps`.

### 3. Анализ предметной области
- Выбрана предметная область и название ИС.
- Определена цель и проведён анализ осуществимости.
- Описаны пользователи и требования к КТС.
- Рассмотрено системное ПО ИС.

### 4. ООП и контроль версий
- Изучены принципы ООП: классы, объекты, свойства, методы.
- Выполнено объектно-ориентированное проектирование для предметной области.
- Оформлен отчёт: сущности, атрибуты, связи, концептуальная модель.

### 5. Основы Python в VS Code
- Освоена работа в VS Code: создание проекта, запуск, горячие клавиши.
- Изучены базовые конструкции: переменные, типы, `print`, `input`, условия, циклы.
- Отработаны структуры данных: списки, словари, кортежи, список словарей.
- Написаны функции: поиск, сортировка, фильтрация, корзина.

### 6. Scrum и Kanban
- Изучены Agile, Scrum, Kanban.
- Составлен Product Backlog из 10+ User Story.
- Спланирован спринт, создана Kanban-доска с WIP-лимитом.
- Проведены Daily Standup и ретроспектива.

### 7. Углублённая работа с Git
- Освоен Git Flow: `main`, `develop`, `feature/*`, `hotfix/*`.
- Созданы ветки, выполнены слияния, разрешён конфликт.
- Имитирован Pull Request, выполнен hotfix.
- Визуализирована история коммитов.

### 8. Отладка и тестирование (unittest)
- Изучены виды тестирования.
- Написаны модульные тесты с `unittest`.
- Освоена отладка в VS Code: breakpoints, Step Over/Into/Out.
- Написаны тесты для корзины и ожидаемых ошибок.

### 9. Интеграция модулей
- Монолит разделён на модули: `catalog`, `cart`, `orders`, `analytics`, `storage`.
- Настроены импорты.
- Написаны интеграционные тесты полного цикла.
- Создан скрипт сборки `build.py`.
- Внесена и исправлена ошибка несовместимости форматов.
