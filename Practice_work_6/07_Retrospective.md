# Retrospective — Спринт №1

## Что прошло хорошо?

- Удалось заранее распределить задачи по приоритетам.
- Задачи были разбиты на небольшие технические этапы.
- Реализованные функции были протестированы.
- Kanban-доска помогла контролировать состояние задач.

## Что можно улучшить?

- Более точно оценивать время выполнения отдельных задач.
- Добавить больше автоматических тестов.
- Чётче распределять задачи между участниками команды.

## Что попробуем в следующем спринте?

1. Использовать более подробное планирование задач.
2. Увеличить количество автоматических тестов.
3. Регулярно обновлять Kanban-доску после выполнения каждой задачи.

## Конкретные улучшения

- Проводить короткую проверку прогресса в середине занятия.
- Ограничивать количество одновременно выполняемых задач согласно WIP.
- Добавить автоматическое тестирование основных функций.
