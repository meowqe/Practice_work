## US-1. Товары с низким остатком
**Как** менеджер магазина, **я хочу** видеть товары с низким остатком, **чтобы** вовремя заказывать новую партию.

**Критерии приёмки:**
- Отображаются товары, у которых суммарное количество ≤ 3.
- Список отсортирован по возрастанию количества.
- Если таких товаров нет, выводится сообщение «Нет товаров с низким остатком».

**Оценка:** 3 story points  
**Приоритет:** Высокий

## US-2. Поиск товаров
**Как** менеджер магазина, **я хочу** искать товары по названию и бренду, **чтобы** быстро находить нужный товар.

**Критерии приёмки:**
- Поиск выполняется по названию.
- Поиск выполняется по бренду.
- Результаты выводятся в удобном виде.
- При отсутствии результатов выводится соответствующее сообщение.

**Оценка:** 5 story points  
**Приоритет:** Высокий

## US-3. Аналитика по категориям
**Как** менеджер магазина, **я хочу** видеть количество товаров по категориям, **чтобы** анализировать ассортимент.

**Критерии приёмки:**
- Для каждой категории подсчитывается количество товаров.
- Результат выводится в виде словаря или таблицы.
- Все категории учитываются.

**Оценка:** 5 story points  
**Приоритет:** Средний

## US-4. Оформление заказа
**Как** менеджер магазина, **я хочу** оформлять заказ и сохранять его в JSON, **чтобы** сохранять информацию о заказах.

**Критерии приёмки:**
- Можно сформировать заказ из выбранных товаров.
- Заказ содержит товары и их количество.
- Заказ сохраняется в файл JSON.
- JSON-файл корректно читается.

**Оценка:** 8 story points  
**Приоритет:** Высокий
