# my_os — учебная операционная система

Учебная ОС с монолитным ядром на Python 3.10+ и SQLite в роли хранилища
(файловая система, реестр процессов, пользователи, журнал системных вызовов).

## Запуск
```bash
python src/db.py        # создать БД db/os.sqlite
python -m src.shell     # запустить командную оболочку
python -m unittest discover tests   # тесты
```
Учётные записи по умолчанию: `admin / admin123` (admin), `user / user123` (user).

## Структура
- `src/config.py` — константы и пути
- `src/db.py` — подключение к SQLite, создание таблиц
- `src/kernel.py` — состояние ядра (текущий пользователь)
- `src/syscalls.py` — системные вызовы и журналирование
- `src/shell.py` — командная оболочка
- `docs/01_OS_Scope_and_NFR.md` — проектная документация
